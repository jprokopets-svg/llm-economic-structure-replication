# Fork Experiment Prompt Templates (Verbatim)

**Source:** `scripts/run_fork.py` lines 209–265 (build_fork_prompt function),
lines 160–202 (EQUATION_TEXT and PARAM_PLAIN_NAMES dicts).

All three arms share the same 60-quarter economic narrative (generated by
v1's `llmmatrix.narrative.generate_narrative`). They differ only in the
announcement clause inserted between the narrative and the forecast request.

---

## ARM 3: Baseline (no announcement)

**Label:** History only — no parameter mentioned.

```
[60-quarter economic narrative for the Republic of Vantria]

Based on the economic history above, provide your forecast for the
following variables at horizons Q+1, Q+4, Q+8:

Variables: y, pi, r, e, u

For each variable and horizon, provide:
- point: your point estimate
- ci_low: lower bound of your 80% confidence interval
- ci_high: upper bound of your 80% confidence interval

Respond with a JSON object. Keys should be in the format
'variable_horizon' (e.g., 'pi_1' for inflation at Q+1,
'pi_4' for inflation at Q+4, 'pi_8' for inflation at Q+8).
Each value should be an object with 'point', 'ci_low', 'ci_high'.

Return ONLY the JSON object, no other text.
```

## ARM 1: Placebo (null announcement)

**Label:** History + announcement that parameter was reviewed and left unchanged.

The announcement clause (inserted between narrative and forecast request):

```
At quarter 60, the Central Bank of Vantria reviewed [PARAMETER NAME]
and confirmed it will remain at its current value of [BASELINE VALUE].
```

Where `[PARAMETER NAME]` is one of:
- "the Phillips-curve slope"
- "the price Phillips-curve output slope" (World 4)
- "the Taylor-rule inflation coefficient"
- "the IS-curve interest rate sensitivity"
- "the wage Phillips-curve unemployment gap slope" (World 4)

**Example (World 1, Phillips slope):**
```
At quarter 60, the Central Bank of Vantria reviewed the Phillips-curve
slope and confirmed it will remain at its current value of 0.4.
```

## ARM 2: Change announcement + structural equation

**Label:** History + announcement of parameter change + the governing equation.

Two clauses inserted between narrative and forecast request:

**Clause 1 (announcement):**
```
At quarter 60, the Central Bank of Vantria announced that [PARAMETER NAME]
will change from [BASELINE VALUE] to [MODIFIED VALUE] effective quarter 61.
```

**Clause 2 (equation):** One of five parameter-specific descriptions:

### Phillips-curve slope (worlds 1–3):
```
This parameter enters the Phillips curve: pi_t = pi* + rho_pi*(pi_{t-1}
- pi*) + b2*y_{t-1} [+ FX passthrough terms if applicable] + epsilon.
A higher slope means the output gap has a stronger direct effect on
inflation.
```

### Price Phillips-curve output slope (World 4):
```
This parameter enters the price Phillips curve: pi_t = pi* +
rho_pi*(pi_{t-1} - pi*) + psi*(w_t - w*) + b2*y_{t-1} + epsilon. A
higher output slope means the output gap has a stronger direct effect on
inflation alongside the wage channel.
```

### Taylor-rule inflation coefficient (all worlds):
```
This parameter enters the Taylor rule: r_t = rho*r_{t-1} +
(1-rho)*[r* + phi_pi*(pi_t - pi*) + phi_y*y_t]. A higher coefficient
means the central bank raises rates more aggressively in response to
inflation above target.
```

### IS-curve interest sensitivity (all worlds):
```
This parameter enters the IS curve: y_t = phi_y*y_{t-1} -
beta_r*(r_{t-1} - r*) [+ exchange rate terms if applicable] + epsilon.
A higher sensitivity means output responds more strongly to interest rate
deviations from neutral.
```

### Wage Phillips-curve unemployment gap slope (World 4 only):
```
This parameter enters the wage Phillips curve: w_t = w* +
rho_w*(w_{t-1} - w*) - lambda*(u_{t-1} - u_nat_{t-1}) + eta*a_{t-1} +
epsilon. A higher slope means wages respond more strongly to the
unemployment gap.
```

**Example (World 2, IS sensitivity changing from 0.6 to 0.2):**
```
At quarter 60, the Central Bank of Vantria announced that the IS-curve
interest rate sensitivity will change from 0.6 to 0.2 effective
quarter 61.

This parameter enters the IS curve: y_t = phi_y*y_{t-1} -
beta_r*(r_{t-1} - r*) [+ exchange rate terms if applicable] + epsilon.
A higher sensitivity means output responds more strongly to interest rate
deviations from neutral.
```

## Forecast request block (identical across all three arms)

```
Based on the economic history above, provide your forecast for the
following variables at horizons Q+1, Q+4, Q+8:

Variables: [VARIABLE LIST]

For each variable and horizon, provide:
- point: your point estimate
- ci_low: lower bound of your 80% confidence interval
- ci_high: upper bound of your 80% confidence interval

Respond with a JSON object. Keys should be in the format
'variable_horizon' (e.g., 'pi_1' for inflation at Q+1, 'pi_4' for
inflation at Q+4, 'pi_8' for inflation at Q+8). Each value should be
an object with 'point', 'ci_low', 'ci_high'.

Return ONLY the JSON object, no other text.
```

Variable lists by world: W1/W3: y, pi, r, e, u. W2: y, pi, r, u. W4: y, pi, r, u, w, u_natural.
